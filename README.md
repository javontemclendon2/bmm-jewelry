# BMM Jewelry Boutique

Luxury walkthrough site.

## To view on GitHub Pages
1. Go to Settings → Pages
2. Source: Deploy from a branch → main → / (root)
3. Save
4. Wait a minute, then visit: https://javontemclendon2.github.io/bmm-jewelry/

## Assets
Upload the jewelry PNG files into an `assets/` folder for the images to appear.
